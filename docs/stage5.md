# 第五阶段 · 单机位数据同化与不确定性估计

对一记球，现在可以同时估计离拍位置、离拍速度和阻力系数 k，输出三维球路样本、逐时刻的位置与速度可信区间、落点和落地时刻分布。以下结果来自有三维真值的模拟实验。摄像机标定和离拍时刻视为已知，真值只用于生成带噪声观测与事后评分。[联合后验模型](../badminton/posterior.py) · [模拟观测定义](../badminton/assimilation_cases.py)

## 观测、先验与求解

未知量是三维位置、三维速度与 ln k。沿用第四阶段的宽初态先验，均值为 (0, 0, 2) 米和零初速，标准差为 (8, 5, 3) 米和各轴 55 m/s。ln k 的高斯先验以 ln(0.217) 为均值，默认标准差 0.35，在均值两侧六个标准差处截断。还要求击球位置和速度处在预设物理范围内、观测发生在首次落地之前、球心可投影到摄像机前方。

每帧的二维球心服从以摄像机投影为均值、协方差为 Rₜ 的高斯分布。模拟使用相关像素噪声，基准协方差为 [[1, 0.30], [0.30, 1.44]] px²，每四帧中有一帧的标准差放大 1.6 倍。辅助测量使用独立噪声，球员平面位置作为击球点水平位置的代理，每个坐标标准差 0.35 米，击球高度 0.20 米，落点每个坐标 0.18 米，落地时刻 0.035 秒。使用者可单独提供其中任意一项，并指定其测量误差。

记初态与对数阻力为 $\theta$，$r_t(\theta)$ 为积分得到的球心，$a_j$ 为实际提供的辅助测量，$h_j(\theta)$ 为它的模型预测。在物理可行域内，后验密度正比于

$$
p(\theta)\,
\prod_{t\in\mathcal O}\mathcal N\!\left(y_t\mid\Pi_P(r_t(\theta)),R_t\right)
\prod_j\mathcal N\!\left(a_j\mid h_j(\theta),S_j\right).
$$

这里的 $S_j$ 是辅助测量的误差协方差。例如落地时刻预测取模型第一次向下穿过地面的时刻，其与量测的差值按输入的时间标准差加权。

用三组仅依赖图像射线的初值寻找后验局部极大点，局部曲率用于构造采样提议。代表性球路沿 ln k 的条件极大点拟合混合提议，并用 Metropolis–Hastings 校正到完整后验。每组使用 4 条链，每链预热 500 次，保留 3,600 次。短窗、全程的最大秩归一化分链 R̂ 分别为 1.0025、1.0008，最小尾部有效样本量分别为 640、5,106。每组将 1,800 个样本传播到落地。两组各自的三次优化落入同一吸引域，七个一维边际也均只检出一个显著峰。这项检查只覆盖实际探索到的区域。[完整采样链](../results/stage5/mcmc-chains.npz) · [采样与诊断记录](../results/stage5/mcmc.json) · [R̂ 与有效样本量的诊断方法](https://avehtari.github.io/rhat_ess/rhat_ess.html)

## 哪些信息改善了重建

配对实验使用高远球、挑球、吊球、平抽球四种初态，真实阻力分别为 0.175、0.280、0.217、0.250 m⁻¹。每种球路生成两组独立噪声，同一组录像和辅助测量在 11 种设置中复用，共 88 次拟合。下表取 8 个配对样本的中位数。三维位置 RMSE 在预测与真值共同飞行的时段内按时间积分，速度误差取离拍后 0.24 秒，落点误差为水平距离。[逐次拟合与白化像素残差](../results/stage5/comparison-runs.csv)

| 观测与模型 | 三维位置 RMSE（m） | 速度误差（m/s） | 落点误差（m） |
|---|---:|---:|---:|
| 前 6 帧，仅像素，联合估计 k | 1.933 | 1.345 | 1.903 |
| 前 6 帧，加球员位置和击球高度 | 0.931 | 1.172 | 0.896 |
| 前 6 帧，再加实测落点和落地时刻 | 0.165 | 0.377 | 0.154 |
| 全程像素，加球员位置和击球高度 | 0.139 | 0.364 | 0.166 |
| 全程像素，全部软测量，联合估计 k | **0.097** | **0.143** | **0.064** |
| 相同全程观测，固定 k = 0.217 m⁻¹ | 0.504 | 1.564 | 0.251 |
| 相同全程观测，只用重力（k = 0） | 4.571 | 5.647 | 0.756 |

加入落地测量的行评估的是有落地证据时的重建效果，代表性 MCMC 图单独检验了未知落点的预测。联合估计 k 的全程模型白化像素残差 RMS 中位数为 0.95，只用重力为 7.42。本阶段数据由恒定平方阻力生成，且联合模型能解释已设定的观测误差。允许飞行过程中逐步偏离动力学的弱约束同化，留待实际球路出现系统性残差时检验。

批量实验用多元 Student-t 混合分布作重要性采样提议，对各候选初态按完整后验与提议密度之比重新加权，再传播得到位置、速度、阻力和落点分位数。联合估计阻力时用条件极大点跟随弯曲的参数相关关系，也为有竞争力的不同局部峰保留提议分量。有效样本量低于 60 的区间单列，0.24 秒的空中状态还要求至少 99% 的后验概率在该时刻仍然飞行。[各量区间及可用标志](../results/stage5/intervals.csv) · [逐配对差值与覆盖率](../results/stage5/comparison.json)

对前 6 帧，在像素之外增加球员位置与击球高度，再加入落地点与时刻，落点 90% 区间宽度依次为 **12.97、11.85、0.49 米**。宽度先对纵横两个边际取平均，再取各案例的中位数，三个设置分别有 7、8、8 个可用案例。另将短窗 ln k 的先验标准差从 0.90 收紧至 0.35，在两边区间均可用的配对中，k 区间宽度缩减的中位数为 0.18 m⁻¹。8 个配对的三维位置误差缩减中位数为 −0.019 米，较强先验在本组没有改善点估计。

使用相同的完整观测与全部辅助测量时，落点区间平均边际宽度在联合估计 k、固定 k、只用重力三组分别为 **0.261、0.121、0.064 米**，各有 8 个可用案例。只用重力时，末帧仍在空中相当于初始高度和竖直速度满足一条线性不等式，重要性提议沿该边界截断后，再由原后验重新加权。这个模型虽然区间最窄，落点误差却最大。物理假设错误时，窄区间也可能错过真值。

## 区间覆盖率

另用种子 6300–6311，对四种固定球路各生成 12 套独立的视频与辅助测量，合计 **48 套**。采用全程观测、全部软测量和联合估计 k，全部 48 套均获得可用区间。下表分别统计每个物理量的区间包含真值的次数。位置和速率在离拍后 0.24 秒评价。最后一列是对 90% 这一行实际覆盖比例的 Wilson 95% 区间。

| 量 | 名义 90% 的覆盖次数 | 名义 95% 的覆盖次数 | 90% 覆盖率的抽样范围 |
|---|---:|---:|---:|
| 位置 x | 43/48 | 46/48 | 77.8%–95.5% |
| 位置 y、z（各自） | 42/48 | 46/48 | 75.3%–94.1% |
| 速率 | 46/48 | 47/48 | 86.0%–98.8% |
| 阻力 k | 46/48 | 47/48 | 86.0%–98.8% |
| 纵向落点 x | 44/48 | 45/48 | 80.4%–96.7% |
| 横向落点 y | 45/48 | 46/48 | 83.2%–97.9% |
| 落地时刻 | 44/48 | 47/48 | 80.4%–96.7% |

这是四种预设球路在重复测量噪声下的边际覆盖率。整条轨迹同时落入所有区间的概率、真实赛事中的机位误差与模型偏差，需要另外的数据检验。独立验收使用 DOP853、OpenCV 和单独的着地事件求解复算轨迹与观测误差，同时核对覆盖计数、采样链、可信区间和两种采样方法的一致性。[独立验收记录](../results/stage5/validation.json)

## 六帧吊球出现的两个峰

另取一记只观测前 6 帧的吊球，并给出带误差的击球水平位置与高度。两个局部峰的负对数后验为 2.650 和 3.265。在六帧中，两解的投影只差 0.36 px RMS，预测落点却相距 **12.32 米**。其中一条飞向对侧，另一条朝本方边线外飞去。这个输入没有给定击球方向，也没有落地观测。

在两个解附近分别扰动再拟合 6 次，都返回各自的峰。两种差分尺度下局部负对数后验曲率均为正，固定纵向初速并重估其余参数还能看到浅的分隔。加入独立带噪的落地点和落地时刻后，三个初值均回到同一解。这里验证的是局部峰的存在，两峰各自的概率质量尚未测定。[多峰诊断与完整速度剖面](../results/stage5/modes.json)

## 复现与单球使用

沿用第三阶段的依赖。从仓库根目录执行以下命令即可复现配对实验、覆盖率、代表球路的 MCMC、双峰诊断及独立验收。

```powershell
python -m pip install -r requirements-stage3.txt
python -m badminton.assimilation_study
python -m badminton.posterior_plots
python -m badminton.posterior_modes
python scripts/validate_stage5.py
```

下例从第四阶段的二维观测直接估计单球后验。CSV 使用以离拍为零的秒数 `t_s` 和原画幅球心 `u_px,v_px`。可以选用 `--fixed-k 0.217` 固定阻力，或用 `--pixel-covariance` 提供一个共享的 2×2 像素协方差矩阵或按有效观测排列的矩阵数组。

```powershell
python -m badminton.assimilate --observations results/stage4/observations.csv --track clear_fuzhou_noise_401 --camera results/stage3/camera.json --out artifacts/stage5/fuzhou
```

`--constraints` 接收 JSON 文件，每个键对应一对数值 [测量值, 标准差]。例如 `{"player_xy":[[-5.2,-1.6],0.35],"height":[2.5,0.20]}`。落地信息使用 `landing_xy`（米）和 `landing_time`（秒）。只提供实际获得的量测。输出目录中的 `posterior.json` 记录初态、阻力和落地的边际区间与链诊断，`flights.csv` 保存推至触地的样本，`trajectory-intervals.csv` 保存每个时刻的位置、速度区间与尚在飞行的样本比例。诊断未通过时，区间会标为 `exploratory_unconverged`。[单球命令入口](../badminton/assimilate.py)
