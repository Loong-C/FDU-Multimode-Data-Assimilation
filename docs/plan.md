# 基于多模态数据同化的羽毛球三维轨迹重建项目

## 项目总体目标

给定普通羽毛球比赛视频，结合羽毛球二维位置、球场几何、运动员位置、击球声音以及羽毛球空气动力学模型，利用数据同化方法重建具有真实物理尺度的三维运动轨迹，并对重建结果的准确性和不确定性进行分析，最终实现可交互的三维比赛回放。

项目以 Python 为主要开发语言，优先使用 NumPy、SciPy、OpenCV、PyTorch、Matplotlib 和 Plotly 等成熟工具。尽量复用已有视觉识别模型，将研究重点集中在数据同化与三维状态估计上，不必自行训练大型神经网络。

项目按以下阶段逐步开展。每个阶段均需要保留可独立运行的程序、实验数据、实验结果及简洁的说明文档。在完成并验证当前阶段之前，不应盲目进入下一阶段。

## 阶段一：数据集调查与准备

**任务**

调查、下载并检查以下公开项目及数据集：

- BFMD：https://github.com/Ning-D/BFMD
- MonoTrack：https://github.com/kyunghyunlim/MonoTrack
- TrackNetV3：https://github.com/qaz812345/TrackNetV3

重点确认数据中是否包含原始比赛视频、羽毛球逐帧二维位置、球场关键点、球网关键点、运动员位置、击球时刻及击球类型。检查数据格式、帧率、坐标定义、标注来源及使用许可。

选择一场画面清晰、主机位稳定的单打比赛，从中提取若干完整回合及不同类型的单次击球片段。

建立统一的数据格式，记录帧编号、时间戳、二维观测坐标、观测置信度、观测是否缺失及击球事件等信息。明确区分人工标注、模型预测和算法补全的数据。

**预期目标**

获得一批可以直接用于后续实验的真实比赛数据，并能够在原始视频上绘制已有的二维轨迹、球场关键点及击球事件，检查时间和空间坐标是否正确对齐。

如果某个数据集不可用，应当寻找替代数据，而不是让整个项目依赖尚未验证的数据来源。

## 阶段二：羽毛球动力学与三维模拟器

**任务**

建立以球场中心为原点、以米为单位的三维世界坐标系。令 x 轴沿球场长度方向，y 轴沿宽度方向，z 轴竖直向上。

建立标准羽毛球场的几何模型，包括地面边线、底线、发球线和球网。

实现羽毛球自由飞行的动力学模型：

\[
\dot{\mathbf r}=\mathbf v,
\qquad
\dot{\mathbf v}=\mathbf g-k\|\mathbf v\|\mathbf v.
\]

其中重力加速度取 9.81 m/s²，阻力参数 k 暂以 0.217 m⁻¹ 为参考值，并允许自由调整。

采用 Runge-Kutta 方法或 SciPy 的数值积分工具求解运动方程。支持指定初始位置、初始速度和阻力参数，并计算完整飞行轨迹、瞬时速度、最高点与落点。

同时实现忽略空气阻力的抛体运动模型，作为后续对照实验的基础。

通过调整初始条件，生成高远球、挑球、吊球、平抽球和杀球等具有不同运动特征的模拟轨迹。

**预期目标**

获得一个独立的三维羽毛球运动模拟器，可以生成具有合理物理特征的轨迹。

使用无阻力情况下的解析解验证数值积分程序的正确性，并检查积分步长对结果的影响。

在三维球场中可视化不同初始条件、不同阻力参数下的轨迹，初步比较平方阻力模型与普通抛体模型的差异。

本阶段暂时不涉及视频识别和数据同化。

## 阶段三：摄像机模型与球场几何标定

**任务**

实现针孔摄像机模型，建立真实三维坐标到图像二维坐标的投影关系：

\[
s
\begin{pmatrix}
u\\v\\1
\end{pmatrix}
=
P
\begin{pmatrix}
x\\y\\z\\1
\end{pmatrix}.
\]

实现根据投影矩阵计算二维坐标，以及根据二维坐标获得对应三维空间射线的功能。

首先在模拟环境中设置一个虚拟摄像机，将第二阶段生成的三维运动轨迹投影为二维图像坐标。

随后利用真实比赛视频中的球场角点、场地线交点、球网立柱顶端等已知三维坐标的关键点估计摄像机投影参数。第一版允许人工标注这些关键点，暂不要求完全自动化。

注意仅使用地面上的共面关键点不能确定一般的三维投影矩阵，需要合理的摄像机内参假设或额外的非共面关键点。检查标定问题的数值稳定性及镜头畸变的影响。

对于镜头切换、移动和变焦的情况，先进行分段处理，不假设整场比赛始终共享同一摄像机参数。

**预期目标**

能够在模拟环境中正确完成三维到二维的投影。

能够对至少一个真实比赛机位完成摄像机标定，并将标准三维球场模型重新投影到原始视频上，与实际球场标线进行比较。

使用未参与标定的关键点检查重投影误差。

本阶段结束后，应当拥有一个完整的正向生成系统：给定羽毛球初始状态和摄像机参数，就能生成其在视频中的二维运动轨迹。

## 阶段四：单次击球的三维轨迹反演

**任务**

这是整个项目的第一个核心研究阶段。

在摄像机参数已知的情况下，仅根据羽毛球在连续视频帧中的二维坐标，尝试反推出羽毛球的三维初始位置、初始速度及完整飞行轨迹。

首先固定阻力参数，将待估变量设为：

\[
\boldsymbol\theta=(\mathbf r_0,\mathbf v_0).
\]

通过动力学方程进行积分，并将生成的三维轨迹投影到二维图像中。

建立以观测重投影误差与初始状态先验为主要组成部分的优化目标：

\[
J(\boldsymbol\theta)=
\sum_{t\in\mathcal O}
\|\mathbf y_t-\Pi_P(\mathbf r_t(\boldsymbol\theta))\|_{R_t^{-1}}^2
+
\|\boldsymbol\theta-\boldsymbol\theta_b\|_{B^{-1}}^2.
\]

使用 SciPy 的非线性最小二乘优化算法求解，并通过多组初始值检查局部最优问题。

首先使用无噪声的模拟数据，随后逐步加入二维位置噪声、随机漏检、连续遮挡和错误检测。

研究不同的观测长度、摄像机角度、初始条件和球路类型对三维反演精度的影响。

模拟轨迹的真实三维坐标不得用于初始化或优化，只能用于最终评价。

**预期目标**

在条件良好的模拟场景下，能够稳定地从二维轨迹恢复三维运动轨迹。

获得重建结果与真实轨迹的对比图、三维位置误差和二维重投影误差。

重点研究三维重建的可辨识性：检查是否存在多条不同的三维轨迹，却能产生非常接近的二维投影。

如果本阶段无法稳定获得合理结果，应当首先分析观测信息是否充分以及优化问题是否存在歧义，而不是继续增加系统功能。

## 阶段五：数据同化与不确定性估计

**任务**

在第四阶段的基础上，建立完整的概率模型。

将视频检测结果表示为带噪声的观测：

\[
\mathbf y_t=\Pi_P(\mathbf r_t)+\boldsymbol\varepsilon_t,
\qquad
\boldsymbol\varepsilon_t\sim\mathcal N(0,R_t).
\]

将初始位置、初始速度和阻力参数视为具有先验分布的未知量，研究其联合后验分布。

引入不同来源的约束，包括运动员在击球时刻的位置、合理的击球高度，以及实际观察到的落地事件等。所有存在测量误差的信息原则上应当采用软约束，而不是强制指定精确坐标。

将阻力参数 k 扩展为可估计参数，比较固定阻力参数与联合参数估计的表现。

对少量代表性轨迹尝试采用 MCMC 方法进行后验采样，或者在后验近似单峰且局部曲率稳定时使用高斯近似，获得一组可能的三维轨迹。

进一步考虑允许物理模型存在误差的弱约束变分同化，但只有当现有模型存在明显不足时才需要实现。

**预期目标**

系统不再只输出一条三维轨迹，而是能够对三维位置、速度、阻力参数和落点的不确定性作出合理估计。

可视化后验轨迹集合、位置可信区间和可能的落点分布。

通过对照实验研究先验信息、连续观测和物理模型分别能够减少多少重建误差及不确定性。

特别注意检查后验分布是否存在多个峰，以及估计区间是否具有合理的实际覆盖率。

## 阶段六：真实单次击球重建与独立验证

**任务**

将此前完成的算法应用于真实比赛视频中的单次击球，首先选择高远球和挑球等具有较长自由飞行阶段的球路，再逐渐测试吊球、杀球等其他类型。

使用人工核对过的二维坐标、摄像机参数和击球时刻进行三维重建，将恢复的轨迹重新投影到原始视频中。

同时，尝试自行拍摄双机位羽毛球实验视频。使用两部固定摄像设备从不同角度记录同一飞行过程，完成摄像机标定和时间同步。

重建算法仅使用摄像机 A 的观测，摄像机 B 的观测保留用于独立验证。将重建轨迹投影到摄像机 B 的图像中进行比较，并在条件允许时通过双目三角测量获得近似的三维参考轨迹。

将用于调整模型参数的数据与最终测试数据分开。

**预期目标**

能够恢复若干真实羽毛球飞行过程的三维轨迹，并证明这些轨迹不仅与原始摄像机画面吻合，也能较好解释另一个独立视角下的观测。

分析真实数据与模拟数据中重建效果的差异，研究空气动力学简化、摄像机标定、时间同步和观测误差造成的影响。

双目三角测量结果应作为具有测量误差的参考值，而不是绝对准确的真实值。

## 阶段七：多模态观测融合与完整回合重建

**任务**

将单次击球的重建算法扩展到包含多次击球的完整回合。

建立分段动力学模型：在相邻击球事件之间使用自由飞行方程；在击球瞬间保持空间位置连续，但允许速度突变。

首先利用已有的击球时刻标注完成分段重建，并处理相邻飞行轨迹在击球位置处的衔接问题。

随后引入比赛音频，通过声音的瞬态特征提取候选击球时刻，再结合二维运动方向变化及运动员位置进行判断。注意处理音视频时间偏移、解说声、观众噪声及其他干扰。

将击球时刻及击球位置作为具有不确定性的额外信息融入同化过程，避免把不可靠的声音检测结果直接视为确定事件。

对于触网、落地、画面外飞行等不满足自由飞行模型的情况，应当识别并进行特殊处理，或者明确标记为无法可靠重建的片段。

**预期目标**

能够将一个完整回合中的多次击球连接成连续的三维空间运动轨迹。

实现真正的视觉与音频多模态信息融合，并通过对照实验检验音频信息能否改善击球时间估计和三维重建结果。

至少能够完整展示若干具有不同击球类型的真实比赛回合。

## 阶段八：系统性实验与结果分析

**任务**

对整个重建算法开展统一的定量实验。所有对照方法应使用相同的测试数据和观测条件。

比较以下模型和方法：

- 不考虑空气阻力的抛体运动模型；
- 固定阻力参数的三维轨迹反演；
- 联合估计阻力参数的三维轨迹反演；
- 引入运动员位置等额外约束的同化方法；
- 引入音频击球事件的多模态同化方法。

如果已经实现弱约束变分同化，再加入相应的对照实验。

研究不同噪声强度、观测缺失比例、连续遮挡长度、摄像机标定误差、击球时刻误差和物理模型失配对结果的影响。

主要评价指标包括三维位置 RMSE、独立视角的二维重投影误差、落点误差、击球时刻误差及可信区间覆盖率。根据不同数据来源实际具备的参考信息选择指标。

报告失败案例和无法可靠重建的情况，不能只展示效果最好的轨迹。

**预期目标**

获得足以支持期末汇报的定量研究结果，回答以下核心问题：

物理动力学模型是否能够改善单目三维轨迹重建？不同观测信息分别贡献了多少有效信息？哪些情况下单目三维重建仍然存在明显歧义？算法给出的不确定性是否能够反映实际误差？

本阶段不要求所有实验都证明所提出的方法更优，真实的负面结果同样具有研究价值。

## 阶段九：整场比赛重建与交互式可视化

**任务**

将此前验证过的模块整合为完整的比赛处理流程。

读取比赛视频与相关标注，自动或半自动地划分回合、提取二维观测、识别击球事件、执行三维轨迹重建并保存结果。

对无法可靠重建的轨迹进行标记，统计有效重建比例，不应人为生成缺乏观测依据的轨迹来填满整场比赛。

使用 Plotly 或其他三维可视化工具，实现具有标准物理尺寸的虚拟羽毛球场。

实现原始比赛视频与三维轨迹的同步回放，支持自由旋转视角、切换俯视与侧视视图、选择比赛回合、调整播放进度以及显示或隐藏不同球路。

进一步展示瞬时速度、飞行高度、击球位置、落点及轨迹不确定性。

**预期目标**

形成一个具有实际展示价值的三维羽毛球比赛回放系统。

在完成核心研究的前提下，尽可能扩展到整场比赛的自动或半自动重建。

最终整理项目代码、实验数据、运行说明、关键实验图表以及适合十分钟期末汇报的演示素材。

## 开发与验收原则

所有工作均在指定项目目录内开展。不同阶段应复用此前已经验证的模块，避免无必要地重复编写代码或过度设计架构。

每个阶段结束后，应当提供实际运行结果，而不是仅仅完成代码编写；说明完成了哪些目标、进行了哪些实验、得出了什么结论，以及还存在什么问题。

所有模拟结果、真实观测、模型预测和参考真值必须明确区分。

在没有可靠验证的情况下，不得仅凭轨迹外观或较小的二维重投影误差宣称三维重建准确。

优先保证数学模型、数据同化算法与实验验证的正确性。整场比赛的自动化处理和精美的可视化属于建立在核心研究成功基础上的扩展目标。
