# TrackNetV3 与 Shuttlecock Trajectory Dataset

TrackNetV3 的论文使用 TrackNetV2 发布的逐帧人工标注数据。本次取自数据发布方的 NYCU 公开压缩包。GitHub 仓库另外提供检测模型、轨迹补全代码及修订过的测试标签。主样本属于专业比赛训练集，使用压缩包内原始标签，没有运行检测或补全模型。[TrackNetV3 仓库](https://github.com/qaz812345/TrackNetV3) · [论文](https://people.cs.nycu.edu.tw/~yushuen/data/TrackNetV3.pdf) · [数据说明与官方压缩包入口](https://hackmd.io/Nf8Rh1NrSrqNUzmO0sQKZw)

## 来源与字段

| 项目 | 发布内容及核对结果 |
|---|---|
| 视频 | 发布说明列有专业训练比赛 23 场、业余训练比赛 3 场，另有专业测试比赛 3 场。下载包中提供的是比赛转播截取的回合 MP4。 |
| 比赛与编号 | 本次取专业训练集 match4 的全部 8 个片段，2019 福州中国公开赛男单决赛，桃田贤斗对周天成。画面可辨认双方记分牌及福州场地。文件名的三个数字依次为局号、全场获胜方在该回合结束时的得分、全场负方当时的得分。 |
| 羽毛球二维位置 | 原 CSV 的 `Frame,Visibility,X,Y`。样本从第 0 帧连续编号；坐标为原画幅像素，原点在左上，横向向右、纵向向下。人工标为不可见时，`Visibility=0` 且坐标填 `0,0`。没有置信度列。 |
| 几何、球员与击球 | 核对的原始目录只有视频和羽毛球 CSV。球场及球网关键点、运动员位置、击球时刻和球种均需取自其他标注或另行记录。 |
| 时间与音频 | 8 段逐帧解码均为 1280 × 720、25 fps 的 MPEG-4 Part 2 视频。每段只含一条视频流，无音轨。将零基帧号除以 25，即得相对片段起点的秒数。数据说明概述为 30 fps，实验应按具体 MP4 确定时间基准。 |
| 使用许可 | 项目 MIT 文本明确覆盖软件、模型权重及相关文档。数据发布页没有列出比赛转播或标签的单独再分发许可，ZIP 中也未发现许可证文件。原始视频可从发布方按需下载。[项目 LICENSE](https://github.com/qaz812345/TrackNetV3/blob/master/LICENSE) · [数据发布页](https://hackmd.io/Nf8Rh1NrSrqNUzmO0sQKZw) |

## 复现

在项目根目录运行以下命令。需要 Python 3 和 OpenCV。`--archive` 可传入已经下载的完整官方 ZIP。默认下载方式只请求目录索引及目标文件的字节范围。脚本通过文件的 SHA-256 核对已下载样本。

```console
python scripts/fetch_tracknetv3.py
```

视频存于 `data/raw/tracknetv3/Professional/match4/video/`，对应原始 CSV 存于同级 `csv/`。四帧预览依次取自 `1_03_02` 第 100 帧、`2_14_17` 第 82 帧、`3_18_17` 第 275 帧及 `1_15_10` 第 220 帧。前三帧展示底线后方主机位，右下角展示转播切换后的侧面特写。每幅图下方标注该视频的时间和零基帧编号。[原视频样帧](../../artifacts/previews/tracknetv3.jpg)
